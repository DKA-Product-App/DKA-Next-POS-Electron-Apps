**DKA Next POS** adalah aplikasi Point of Sale berbasis desktop yang dibangun menggunakan teknologi web modern (Next.js & Electron) untuk memberikan pengalaman kasir yang responsif, cepat, dan handal.

## 📋 Fitur Utama
- **Dashboard Admin**: Manajemen produk, stok, laporan, dan pengaturan toko.
- **Kasir (POS)**: Antarmuka kasir yang intuitif dengan fitur pencarian cepat, split bill, dan manajemen keranjang.
- **Laporan Real-time**: Visualisasi data penjualan harian, mingguan, dan bulanan.
- **Dukungan Hardware**: Integrasi dengan printer thermal dan barcode scanner.
- **Server-Side Pagination**: Penanganan data transaksi dalam jumlah besar dengan efisien.

## 🚀 Memulai (Getting Started)

### Prasyarat
- Node.js (v18+)
- npm / yarn

### Instalasi & Menjalankan
```bash
# Install dependencies
npm install

# Jalankan dalam mode pengembangan (Dev)
npm run dev

# Build untuk produksi
npm run build
```
